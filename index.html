🗄️ Configuration Supabase
Connecte ta base de données en 3 étapes simples
1
Crée un projet Supabase gratuit
Va sur supabase.com → "New Project" → choisis un nom et une région proche (ex: Frankfurt ou Singapore).
→ Ouvrir supabase.com
2
Exécute le script SQL fourni
Dans ton projet : SQL Editor. Colle le contenu de sql/schema.sql et exécute-le pour créer les tables et les règles de sécurité.
3
Récupère tes clés et colle-les ci-dessous
Dans ton projet : Settings → API. Copie la "Project URL" et la clé "anon / public". Les clés sont stockées dans ce navigateur (localStorage). Ne partage jamais ta clé service_role.
Commence toujours par https:// et finit par .supabase.co
